release APK names itself: `META-INF/version-control-info.textproto` contains revision
`1fe2dad77b2f77f960c26deb8b4d7aa465b14583`. The app is classified as a **personal preview**, not a full v1 release.

## Signing and installing

Signing uses the personal key from 0.1.0, certificate SHA-256
`19d1da9a8fe704082a531faed8a24d966c485aae581a7076dd4b4f66c11d3881`; commands are in [BUILD](../BUILD.md). Only with
this certificate does Android accept the APK as an update to an installed 0.1.0. On first start, the app migrates
its database from schema 3 to 4; `MigrationTest` checks the migration from schema 1 through 4 on a test database.
The APK was signed this way on 2026-09-14 and attached to the release. Updating a real 0.1.0 installation with it,
and running the signed 0.2.0 on a device, are NOT_RUN.

## Remaining release boundaries

- **NOT_RUN:** live transcription with AssemblyAI, OpenAI, and Groq. It needs the owner's API keys, which agents may
  not enter; zero paid calls.
- **NOT_RUN:** physical ARM64 device; it needs the owner's phone. Execution covers the named x86_64/API-37/16KB
  emulator only.
- **BLOCKED:** full TalkBack operation, for the reasons in the [0.1.0 report](2026-09-08-preview.md).
- **NOT_RUN:** a measurement on a physical device of how long the app locks its UI at startup. In CI it was more
  than 25 seconds on a freshly installed emulator ([BUGS](../BUGS.md), item 57, closed).
- **NOT_RUN:** signature check of engine updates with Bouncy Castle 1.86 on Android before API 37
  ([BUGS](../BUGS.md), item 55).
- **NOT_RUN for 0.2.0:** live extractor tests, real engine activation during running jobs, and the caption
  end-to-end pass with the release app; these are demonstrated for 0.1.0.
- **NOT_RUN:** updating a real 0.1.0 installation and running the signed 0.2.0 on a device. Signing itself passed on
  2026-09-14; see the table above.
- **Open license task:** the FFmpeg AAR's corresponding-source and license attribution are incomplete; see the
  [license report](2026-09-07-licenses.md).

These are concrete evidence and limits, not a claim of being defect-free.

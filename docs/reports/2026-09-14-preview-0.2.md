## Signieren und installieren

Signiert wird mit dem persönlichen Schlüssel von 0.1.0, Zertifikat SHA-256
`19d1da9a8fe704082a531faed8a24d966c485aae581a7076dd4b4f66c11d3881`; die Befehle stehen in [BUILD](../BUILD.md). Nur
mit diesem Zertifikat nimmt Android die APK als Update einer installierten 0.1.0 an. Beim ersten Start migriert die
App ihre Datenbank von Schema 3 auf 4; `MigrationTest` prüft die Migration von Schema 1 bis 4 an einer
Testdatenbank. Das Update einer echten 0.1.0-Installation und die signierte 0.2.0 auf einem Gerät sind NOT_RUN.

## Verbleibende Freigabegrenzen

- **BLOCKED:** Live-Transkription mit AssemblyAI, OpenAI und Groq. Keine ausdrücklich freigegebenen Testzugänge,
  Inhalte und Kostenrahmen; null kostenpflichtige Aufrufe.
- **BLOCKED / NOT_RUN:** physisches ARM64-Gerät. Die Ausführung gilt für den genannten x86_64-/API-37-/16-KB-Emulator.
- **BLOCKED:** vollständige TalkBack-Bedienung, aus den Gründen im [Bericht zu 0.1.0](2026-09-08-preview.md).
- **NOT_RUN:** eine Messung auf einem physischen Gerät, wie lange die App beim Start ihre Bedienung sperrt. In der CI
  waren es auf einem frisch installierten Emulator mehr als 25 Sekunden ([DEFECTS](../DEFECTS.md), Punkt 57).
- **NOT_RUN:** Signaturprüfung der Engine-Updates mit Bouncy Castle 1.86 auf Android vor API 37
  ([DEFECTS](../DEFECTS.md), Punkt 55).
- **NOT_RUN für 0.2.0:** Live-Tests des Extractors, echte Engine-Aktivierung während laufender Jobs und der
  Caption-Durchstich mit der Release-App; belegt sind sie für 0.1.0.
- **NOT_RUN:** Signatur mit dem persönlichen Schlüssel, Update einer echten 0.1.0-Installation, signierte 0.2.0 auf
  einem Gerät.
- **BLOCKED:** öffentliche APK-Auslieferung wegen fehlender vollständiger FFmpeg-Corresponding-Source-/
  Lizenzzuordnung; Einzelheiten im [Lizenzbericht](2026-09-07-licenses.md).

Dies sind konkrete Nachweise und Grenzen, keine Behauptung der Fehlerfreiheit.

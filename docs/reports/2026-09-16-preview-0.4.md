# Personal preview 0.4.0 — September 16, 2026

Built from commit `f7dd7d2` on `main`, the last commit that changes code for this preview, including the fixes
for the owner's 0.2.0 phone-test P1 and 15 further points, plus a language-parsing fix found while proving the
pipeline against a real Groq request. The unsigned release APK names itself:
`META-INF/version-control-info.textproto` contains revision `f7dd7d2cb047e8e2a25be9989576125df02d9d96`. The app is classified as a
**personal preview**, not a full v1 release. What's new since 0.2.0 is in the [preview guide](../TRY_PREVIEW.md),
review rounds are in [HISTORY](../HISTORY.md), open items by priority and detail are in [BUGS](../BUGS.md). The
[0.2.0 report](2026-09-14-preview-0.2.md) remains the evidence for everything not repeated here. Preview 0.3.0
reached only a version bump (`5ebc11e`) and a crashed release-APK build attempt; it was never signed or published,
and this report is the first release evidence since 0.2.0.

## Signing and installing

Signing uses the personal key from 0.1.0, certificate SHA-256
`19d1da9a8fe704082a531faed8a24d966c485aae581a7076dd4b4f66c11d3881`; commands are in [BUILD](../BUILD.md). Only with
this certificate does Android accept the APK as an update to an installed 0.1.0 or 0.2.0-preview.1. No further
database migration is needed beyond 0.2.0's schema 3→4 change. The APK was signed on `2026-09-16` and
attached to the release. Updating a real 0.1.0 or 0.2.0 installation with it, and running the signed 0.4.0 on a
device, are `verified on the emulator only (16 September 2026, from both old versions), not yet on a physical phone`.

## Remaining release boundaries

- **NOT_RUN:** live transcription with AssemblyAI and OpenAI. It needs the owner's API keys, which agents do not
  enter; zero paid calls from an agent.
- **Run once, not routinely:** live transcription with Groq — `one real request on 16 September 2026 at 22:37 for the 19-second public clip youtube:jNQXAC9IVRw, model whisper-large-v3-turbo, phases RESOLVE, DOWNLOAD_AUDIO, PREPARE_AUDIO, SUBMIT, NORMALIZE, PERSIST, outcome SUCCESS, 4 segments, 197 characters, language en as Groq reported it, no warnings, 32.9 s`. See [BUGS](../BUGS.md)'s
  "Not verified" section for exactly what this does and does not prove.
- **NOT_RUN:** physical ARM64 device; it needs the owner's phone. Execution covers the named x86_64/API-37/16KB
  emulator only.
- **BLOCKED:** full TalkBack operation, for the reasons in the [0.1.0 report](2026-09-08-preview.md).
- **NOT_RUN:** signature check of engine updates with Bouncy Castle 1.86 on Android before API 37 (BUGS item 55,
  untested by the owner's decision).
- **Emulator only:** updating a real 0.1.0 or 0.2.0-preview.1 installation and running the signed 0.4.0 on a
  device.
- **Open license task:** the FFmpeg AAR's corresponding-source and license attribution are incomplete; see the
  [license report](2026-09-07-licenses.md).

These are concrete evidence and limits, not a claim of being defect-free.

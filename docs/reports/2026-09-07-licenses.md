## Project license

SourceScribe's own parts use GPL-3.0-only, by explicit project decision. The full license text was fetched via the
official SPDX license list with a bounded request:

```text
timeout 30s curl -fsSL -o /tmp/sourcescribe-gpl-0.txt \
  https://raw.githubusercontent.com/spdx/license-list-data/main/text/GPL-3.0-only.txt
```

Result: PASS, 232 lines, 34,674 bytes, SHA-256 `fb981668c18a279e285fc4d83fba1e836cc84dd4daa73c9697d3cfd2d8aca6e0`;
`LICENSE` is byte-identical. Direct fetches of `www.gnu.org/licenses/gpl-3.0.txt` were attempted with 30/45-second
timeouts and timed out in this environment; the successful SPDX mirror is therefore named as the actual source, and
no successful direct GNU fetch is claimed.

The GPL choice is a licensing decision for SourceScribe's own parts. It does not by itself classify every UI or app
component regardless of its actual dependencies.
